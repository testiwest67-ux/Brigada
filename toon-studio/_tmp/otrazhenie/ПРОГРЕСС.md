# «Отражение опаздывает» — прогресс

ТЗ как у «Последней электрички»: 9:16, 1080×1920, 30 FPS, ≥1:30 (цель ≈1:40); для TikTok и Shorts.
Сценарий → листы персонажей → голос (voice_check, «ок») → главные кадры (keyframes_sheet, «ок») → анимация →
превью 30 с → полный рендер. Платное (ElevenLabs) — только с разрешения, цену называть заранее.
