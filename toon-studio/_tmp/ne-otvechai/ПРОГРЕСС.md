# Прогресс: «Не отвечай»

## Решения пользователя
- Хоррор-шорт 9:16, 1080×1920, 30 FPS, 45–60 с.
- Озвучка: edge-tts, мужской низкий голос. Платные API не использовать.
- Работать поэтапно: сценарий → кадры → анимация → превью 30 с → «ОК» → финальный рендер.
- Результаты хранить в отдельной папке проекта: `/home/user/Brigada/toon-studio/`.
- Сценарий утверждён («ок»).
- Стиль: **смешанный**. Комнаты, свет и камера в 3D (Three.js), персонажи в 2D (SVG) поверх, их положение высчитывается 3D-камерой.

## Сделано
- Этап 1: сценарий `_tmp/ne-otvechai/СЦЕНАРИЙ.md`, утверждён.
- Студия собрана из `kit/` в `/home/user/Brigada/toon-studio/`, выполнен `npm install`.
- Тест стиля 5 с (кадры 8–9): `_tmp/ne-otvechai/тест-стиля.mp4`. Стиль утверждён («Все ок»).
- Этап 2: все 21 сцена собраны в композиции `NeOtvechai` (56 с). Стоп-кадры: `_tmp/ne-otvechai/кадры-этап2/`, лист: `_tmp/ne-otvechai/лист-этап2.png`. Ждём «ок».
- Кульминация: вместо облёта — «эффект головокружения» (dolly zoom, кадр 18): камера отъезжает сквозь дверь и сужает угол, существо вырастает за Тёмой.

## Код ролика (`src/horror/`)
- `Hall3D.tsx` — 3D-коридор: обои, доски, дверь «под кожу» с глазком, свет с лестницы в щелях, ноги за дверью, лампочка, лунный свет, пылинки.
- `Tema.tsx` — 2D-Тёма: моргание, взгляд, страх, рот, дыхание, руки ко рту, поворот головы, свет сцены (фильтр с каймой).
- `cam.ts` — общая камера для 3D и 2D (проекция).
- `post3d.tsx` — свечение, глитч-шейдер, тон.
- `fx.tsx` — туман, зерно, виньетка, 2D-глитч, субтитры (белые, ключевые слова красные).
- `fonts.ts` — локальный Montserrat (`public/fonts/`).
- `index.ts` + `Root.tsx` — отдельная точка входа для хоррора.
- `sets.tsx` — спальня, лестничная площадка, кухня бабушки (флешбэк).
- `chars.tsx` — мама, бабушка, существо, кулак, рука; `CharSheet.tsx` — лист персонажей.
- `common.tsx` — общая камера/пост для сцен, `Puppet` (2D-персонаж в 3D-мире).
- `shots.tsx` — 21 кадр (S01…S21) и таблица времени `SHOTS`; `Episode.tsx` — сборка ролика.

## Как рендерить в этом облаке
```bash
export TOON_ENTRY=src/horror/index.ts TOON_GL=swangle TOON_BROWSER=/opt/pw-browsers/chromium_headless_shell-1243/chrome-headless-shell-linux64/chrome-headless-shell
node scripts/render.mjs stills HorrorTest _tmp/ne-otvechai/test 20 74 110
```
- Google Fonts из браузера рендера недоступен (сертификат прокси), поэтому шрифт локальный.
- Скачать свой Chrome Remotion не может, поэтому используем готовый headless shell (`TOON_BROWSER`).
- Скорость без видеокарты: около 95 с рендера на 1 с ролика в полном размере (2 потока, 4 ядра).
