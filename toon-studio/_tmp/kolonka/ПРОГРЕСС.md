# «Ева, кто дома?» — прогресс

ТЗ как у «Отражения»: 9:16, 1080×1920, 30 FPS, ≥1:30 (цель ≈1:40); для Shorts (и TikTok/Reels).
Сценарий → листы персонажей → голос (voice_check, «ок») → главные кадры (keyframes_sheet, «ок») → анимация →
превью → полный рендер. Платное (ElevenLabs) — только с разрешения, цену называть заранее.
